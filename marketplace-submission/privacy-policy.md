# Privacy policy draft — Semantic Decision Integration

**Publisher:** ngallodev-software

**Effective date:** Set this date when publishing the policy.

Semantic Decision Integration is an independent, skills-only plugin. It contains instructions, documentation,
templates, and local scaffolding examples. It has no MCP server, does not call the
TypeSafe API, and does not independently collect, transmit, or retain user data.

When a user invokes the skill, the user-selected prompt and any code or context provided
to the coding assistant are processed by the ChatGPT or Codex service under the user's
account and the applicable OpenAI privacy terms and controls. The plugin itself has no
server, analytics, cookies, or separate data-retention system. Users should avoid
including credentials or unrelated sensitive information in prompts. The skill advises
keeping TypeSafe credentials in the consuming application's normal secret-management
boundary; credentials are not needed to use this plugin.

Because the plugin has no data store or support intake, the plugin publisher receives no
user data through the plugin and has no plugin-specific retention period or user-data
deletion mechanism. For questions about this policy, contact the publisher through its
public support channel once that contact URL has been established.

Before publication, the publisher must review this draft against actual plugin behavior,
OpenAI's current terms, applicable law, and its available support contact. Do not publish
this draft unchanged until those checks are complete.
