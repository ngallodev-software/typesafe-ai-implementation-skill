# TypeSafe AI Implementation Skill

A practical engineering playbook for using Jev / System One typed judgments at bounded semantic decision points while keeping application authority in code.

This companion guides ChatGPT and Codex while they help integrate Jev into applications. It does not replace the model that powers the coding agent and does not call the TypeSafe API itself. For current API behavior, follow TypeSafe's [official agent skill](https://docs.typesafe.ai/agent-skill), [coding-agent guide](https://docs.typesafe.ai/introduction/coding-agents), and [documentation index](https://docs.typesafe.ai/llms.txt).
